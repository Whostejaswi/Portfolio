Smart Waste Management System

completed

CleanBin — an AI and IoT-enabled system that monitors bin fill levels, verifies segregation, and rewards responsible disposal.

Personal ML + IoT project

Problem statement

Urban waste management suffers from inefficient collection, poor segregation at the source, and no real-time monitoring — overflowing bins raise costs, pollution, and health risks, while municipalities lack the data to optimise collection.

Solution

CleanBin monitors bin fill levels, verifies proper waste segregation with computer vision, and rewards responsible disposal through a QR-code reward system, giving municipalities a centralised dashboard for real-time monitoring.

Approach

IoT fill-level sensors track accumulation while a YOLOv8-based computer vision pipeline verifies correct segregation before rewarding points — trained on ~3,000 annotated images, reaching 90% accuracy and an F1-score of 0.90. Data streams to a cloud dashboard so collection routes can be optimised.

Status

Completed — trained model, working sensor pipeline, and reward system all integrated and tested.
